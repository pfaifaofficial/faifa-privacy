# นโยบายความเป็นส่วนตัว — พี่ไฟฟ้า (P'Faifa)

หน้าเว็บหน้าเดียวสำหรับใช้เป็นลิงก์นโยบายความเป็นส่วนตัวในหน้าร้าน
Google Play และ Apple App Store ของแอปพี่ไฟฟ้า

ต้นฉบับอยู่ที่ `Egat-Test1/store/privacy-policy.html` ในโปรเจกต์หลัก
ถ้าแก้ต้นฉบับแล้วอย่าลืมคัดลอกมาทับ `index.html` ที่นี่แล้ว push ใหม่

repo นี้ต้องเป็นสาธารณะ เพราะ GitHub Pages บนบัญชีฟรีเปิดให้เฉพาะ repo สาธารณะ
และ Google กำหนดว่าลิงก์นโยบายต้องเปิดดูได้โดยไม่ต้องล็อกอิน
